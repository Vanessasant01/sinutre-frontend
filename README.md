# sinutre-frontend
Interface do sistema SiNutre — Sistema de Ingestão de Macronutrientes.

## 🛠️ Tecnologias
React + Vite + TypeScript + TailwindCSS
Consome a API do repositório sinutre-backend.

## ✨ Funcionalidades
- Tela de login com GitHub
- Painel inicial com resumo de refeições e nutrientes
- Cadastro e visualização de refeições
- Controle de dados diários e mensais

## 🆕 Melhorias e inovações adicionadas
- Busca rápida por nome da refeição
- Lista de refeições ordenada automaticamente em ordem alfabética
